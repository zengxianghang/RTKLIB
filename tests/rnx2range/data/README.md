# Test fixture provenance

`rinex4_mixed_obs.rnx` is a hand-authored RINEX 4.02 observation fixture based
on the field layouts in the official RINEX 4.02 Appendix A2/A3 tables. It is
kept as static input (not generated by the RANGEA encoder) and exercises the
RINEX 4 two-character `X1` receiver-channel observation, `DBHZ`, LLI bit 1 and
an observation line longer than 80 columns.

The test suite also reads RTKLIB's pre-existing external TEQC/GSI fixture at
`test/data/rinex/07590920.05o`; therefore validation is not limited to inputs
created by this converter's tests.

`legacy_70_satellites.rnx` is a capacity regression vector with 70 legal
GPS/Galileo/QZSS satellite identifiers. It verifies both the converter's
dynamic path and the legacy RTKLIB reader's `MAXOBS` boundary behavior.
